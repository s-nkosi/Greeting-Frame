# Greeting GUI 🖥️

A simple **Java Swing GUI application** that demonstrates how to build a graphical user interface using `JFrame`, `JPanel`, `JLabel`, `JTextField`, `JTextArea`, and `JButton`.

## 📌 About the Project

The Greeting GUI allows a user to enter their **name and surname** and provides a simple greeting interface.

This project was created as part of my journey in learning **Java GUI development and Object-Oriented Programming**.

## 🛠️ Technologies Used

* Java ☕
* Java Swing
* NetBeans
* JFrame
* JPanel
* JLabel
* JTextField
* JTextArea
* JButton

## 🧩 GUI Structure

The application is built using several panels:

* **Header Panel** – Displays the "Greeting App" heading.
* **Name Panel** – Allows the user to enter their name.
* **Surname Panel** – Allows the user to enter their surname.
* **Greeting Text Panel** – Displays the greeting message.
* **Button Panel** – Contains the Greet, Clear, and Exit buttons.
